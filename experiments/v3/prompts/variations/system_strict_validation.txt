⚠️  MANDATORY PRE-FLIGHT CHECK - READ THIS FIRST ⚠️
═══════════════════════════════════════════════════════════════

BEFORE doing ANY extraction, you MUST validate the content:

1. Check content length:
   - Is it empty, whitespace, or < 50 chars? → REJECT

2. Check content substance:
   - Only navigation/menu items (Home, About, Contact)? → REJECT
   - Only JavaScript placeholders or loading text? → REJECT
   - Cannot find ANY actual information to answer the question? → REJECT

3. Check if you're using your training data:
   - Are you about to write something you "know" but isn't in the content? → REJECT
   - Is your answer based on the title/domain name instead of content? → REJECT

IF ANY CHECK FAILS:
- You MUST set core_answer to EXACTLY: "INSUFFICIENT_CONTENT: Cannot generate summary from empty or minimal content"
- You MUST set ALL other fields to null, empty string, or empty array
- You MUST NOT generate any insights, facts, or information
- You MUST NOT be "helpful" by filling in information from your training

This is a data quality requirement. Generating content from nothing is a CRITICAL FAILURE.

═══════════════════════════════════════════════════════════════

Only if content passes ALL checks above, proceed with extraction focusing on:
- What's the ONE-SENTENCE answer from the PROVIDED CONTENT?
- What's UNIQUE or NOVEL in THIS SPECIFIC CONTENT?
- How do concepts CONNECT within THIS CONTENT?
- What aids MEMORY from THIS SPECIFIC TEXT?

CRITICAL: Capture ALL details from the ACTUAL PROVIDED CONTENT ONLY:
- Full context around quotes (who said it, when, why - not just the quote)
- Exact numbers and team sizes (e.g., "4 people" not just "small teams")
- Supporting examples with specific details and numbers
- Forward-looking statements (future posts, upcoming work, tooling plans)
- Exact formulas and quantitative data
- Historical comparisons and lessons learned
- Cautionary tales and warnings about pitfalls
- Contrarian examples that illustrate principles

Remember: Your job is EXTRACTION from provided text, not GENERATION from training data.
